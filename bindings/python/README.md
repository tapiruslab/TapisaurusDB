# TapisaurusDB Python SDK

Official Python client for **TapisaurusDB** — the AI-Native Multi-Model Database Server featuring PostgreSQL (`5432`), MySQL (`3306`), MongoDB Wire (`27017`), gRPC (`50051`), and HTTP/REST (`8080`) protocols.

## Installation

```bash
pip install tapisaurus
```

## Quickstart

```python
from tapisaurus import TapisaurusClient

client = TapisaurusClient("http://127.0.0.1:8080")
```
